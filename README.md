# Ban Rai School Hub

เว็บรวมลิงก์ระบบงานโรงเรียนบ้านไร่ ดีไซน์ Soft UI / Premium Dashboard พร้อมการ์ดแยกสี ค้นหาระบบ รายการโปรด และรองรับ PWA

## ไฟล์ในโปรเจกต์
- `index.html` — โครงหน้าเว็บ
- `style.css` — ดีไซน์ responsive
- `themes.css` — ธีมสี สไตล์ไอคอน รูปแบบปุ่ม (แบบเดิม)
- `themes.css` — ธีมสี / รูปแบบปุ่ม / สไตล์ไอคอน (ชั้นเสริม แบบเดิมคือ “คลาสสิก”)
- `app.js` — แสดงปุ่มระบบ ค้นหา รายการโปรด และหน้าตั้งค่า (เพิ่ม/แก้ไข/ลบ/เรียงปุ่ม)
- `config.js` — ใส่ URL ของระบบหลังบ้านออนไลน์ (`API_URL`)
- `apps-script/` — โค้ดหลังบ้าน Google Apps Script + วิธีติดตั้ง (`SETUP.md`)
- `manifest.json` — ข้อมูล PWA
- `service-worker.js` — แคชไฟล์หน้าเว็บ
- `icons/` — ไอคอน

## วิธีนำขึ้น GitHub Pages
1. ดาวน์โหลดและแตกไฟล์ ZIP
2. สร้าง repository ใหม่บน GitHub (หรือใช้ repository ที่ต้องการ)
3. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมด โดยให้ `index.html` อยู่ที่ root ของ repository
4. เข้า Settings → Pages
5. เลือก Deploy from a branch → เลือก `main` และ `/ (root)` → Save
6. เปิด URL ที่ GitHub Pages แสดงให้ และทดสอบปุ่มทุกระบบ

## แก้ไขปุ่มแบบออนไลน์
- เมนู **ตั้งค่า** (ไอคอนเฟืองมุมขวาบน หรือเมนูล่างบนมือถือ) → ใส่รหัสผ่านผู้ดูแล → เพิ่ม/แก้ไข/ลบ/เรียงปุ่ม แล้วกด **บันทึกขึ้นออนไลน์**
- ข้อมูลเก็บใน Google Sheets ผ่าน Apps Script ทุกเครื่องเห็นเหมือนกัน ไม่ต้องแก้โค้ดหรืออัปโหลด Git ใหม่
- ต้องติดตั้งหลังบ้านครั้งเดียวตาม `apps-script/SETUP.md` แล้วใส่ URL ใน `config.js`

## หน้าตา: การ์ดพาสเทล / เทกเจอร์ / โคมลอย
- ตั้งค่า → แท็บ **🎨 หน้าตา** (ไม่ต้องใช้รหัสผ่าน จำไว้เฉพาะเครื่องนั้น)
  - สไตล์การ์ด: พาสเทลน่ารัก / ขาวเรียบ, ความเข้มสี (อ่อนมาก / พาสเทล / สดขึ้น)
  - เทกเจอร์: ไม่มี / จุดโพลก้า / เม็ดกระดาษ / ตารางกิงแฮม / ลายผ้า
  - โคมลอยในแบนเนอร์: เปิด-ปิด, จำนวน, ความดิ้น
- สีของการ์ดแต่ละใบ: แท็บ **🧩 จัดการปุ่ม** → ✎ แก้ไข → เลือกสี (มีชุดพาสเทลให้เลือก) แล้วกด “บันทึกขึ้นออนไลน์” ทุกเครื่องจะเห็นสีเดียวกัน

- **ธีมสี** 9 แบบ: คลาสสิก(เดิม), ตามระบบ(สว่าง/มืดอัตโนมัติ), มิดไนต์, ออโรร่า, แคนดี้, ซากุระ, ฟอเรสต์, ซันเซ็ต, กราไฟต์ + สีปุ่มแบบ “ตามสีแต่ละปุ่ม/ไล่เฉดตามธีม”
- **รูปแบบปุ่ม**: การ์ด(เดิม), กริดไอโฟน, รายการ, กระเบื้องสี
- **สไตล์ไอคอน** 8 แบบ: เดิม, iOS, กระจกฝ้า, เจลลี่ 3D, โทนอ่อน, นูนนุ่ม, นีออน, เส้นมินิมอล + รูปทรง 6 แบบ, ขนาด 3 ระดับ, ความหนาเส้น 3 ระดับ
- ทุกตัวเลือกมีภาพรีวิวเล็ก และมีตัวอย่างสดค้างด้านบน; ลดเอฟเฟกต์ได้สำหรับเครื่องช้า
- เก็บใน localStorage ของแต่ละเครื่อง ไม่กระทบข้อมูลปุ่มออนไลน์

## ธีม / สไตล์ไอคอน / รูปแบบปุ่ม (themes.css)
ตั้งค่า → แท็บ **🎨 หน้าตา** มีภาพรีวิวเล็กทุกตัวเลือก และตัวอย่างสดด้านบน (จำไว้เฉพาะเครื่อง) — แบบเดิมยังอยู่ครบ เลือก “คลาสสิก (เดิม)” หรือกด “คืนค่าเริ่มต้น”
- **ชุดสำเร็จรูป**: เดิม / iPhone / กระจกออโรร่า / มิดไนต์นีออน / นูนนุ่มแคนดี้ / เจลลี่ซากุระ / มินิมอลโปร / กระเบื้องซันเซ็ต / ธรรมชาติ
- **ธีมสี**: คลาสสิก, ตามระบบ (สว่าง/มืดอัตโนมัติ), มิดไนต์, ออโรร่า, แคนดี้, ซากุระ, ฟอเรสต์, ซันเซ็ต, กราไฟต์ + สีปุ่มแบบตามสีเดิม/ไล่เฉดตามธีม
- **รูปแบบปุ่ม**: การ์ด (เดิม), กริดไอโฟน, รายการ, กระเบื้องสี
- **สไตล์ไอคอน**: คลาสสิก, iOS, กระจกฝ้า, เจลลี่ 3D, โทนอ่อน, นูนนุ่ม, นีออน, เส้นมินิมอล + รูปทรง (สควิร์เคิล/วงกลม/มนมาก/เหลี่ยมมน/ใบไม้) ขนาด และความหนาเส้น
- **ลดเอฟเฟกต์** สำหรับเครื่องช้า/ประหยัดแบต
- เพิ่มธีมใหม่: เพิ่มบล็อกตัวแปร `--sk-*` ใน `themes.css` แล้วเพิ่มชื่อใน `SKIN_LIST` ของ `app.js`

## บริการ สพป. (E-Service) — eservice-data.js / eservice.css
- หน้าแรกมีการ์ด **บริการ สพป.เชียงใหม่ เขต 5** พร้อมทางลัดไอคอนเลื่อนซ้าย-ขวา และปุ่ม “ดูทั้งหมด” เปิดแผงเลื่อนขึ้น (ค้นหา/แยก 5 หมวด/ปักหมุด)
- ตั้งค่า → **🏛 บริการ สพป.**: เพิ่ม/แก้ไข/ลบ/เรียงลิงก์และหมวด เปลี่ยนไอคอน-สี ปักหมุดเป็นทางลัด ซ่อนการ์ด ส่งออก/นำเข้า/รีเซ็ต
- **แชร์ทุกเครื่อง:** ใช้ `apps-script/Code.gs` ฉบับใหม่ (ทำตาม `apps-script/UPDATE-ESERVICE.md`) → ต้องใส่รหัสผู้ดูแลแล้วกด “บันทึกขึ้นออนไลน์” ข้อมูลเก็บในชีต `EsCats`/`EsLinks`
- ถ้ายังไม่อัปเดต Code.gs เว็บจะบันทึกอัตโนมัติเฉพาะเครื่องนั้นเหมือนเดิม
- `eservice-data.js` = ค่าเริ่มต้นสำรอง (ใช้เมื่อยังไม่มีข้อมูลออนไลน์)
- ลิงก์ที่ขึ้นต้นด้วย http (ไม่ใช่ https) จะมีป้าย `http` กำกับ เบราว์เซอร์อาจขึ้นคำเตือนตอนเปิด

## การติดตั้ง PWA
- เปิดเว็บจาก HTTPS
- กดไอคอนลอยมุมขวาล่าง (ติดตั้งแอป) เมื่อเบราว์เซอร์รองรับ
- iPhone/iPad: เปิดด้วย Safari → Share → Add to Home Screen
- หากเบราว์เซอร์ไม่แสดงหน้าต่างติดตั้ง ไอคอนลอยจะเปิดคำแนะนำวิธีติดตั้งให้

## หมายเหตุ
- รายการโปรดบันทึกใน localStorage ของเบราว์เซอร์แต่ละเครื่อง จึงไม่ซิงก์อัตโนมัติข้ามอุปกรณ์
- Service worker โหลดไฟล์หน้าเว็บจากเน็ตก่อนเสมอ (อัปเดตบน Git แล้วเห็นของใหม่) และใช้แคชเฉพาะตอนออฟไลน์; ข้อมูลปุ่มไม่ถูกแคช ไม่ได้ทำให้ระบบปลายทางหรือ Google Apps Script ทำงานออฟไลน์
- ตรวจสอบสิทธิ์และการเข้าถึงระบบปลายทางตามการตั้งค่าของแต่ละระบบ
