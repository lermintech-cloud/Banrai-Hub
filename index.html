INSTALL SCHOOL HUB

เพิ่มไว้บนหน้าจอหลัก

01

Android / Chrome
กดเมนู ⋮ ของเบราว์เซอร์ แล้วเลือก “ติดตั้งแอป” หรือ “เพิ่มลงในหน้าจอหลัก”

02

iPhone / iPad
เปิดด้วย Safari กดปุ่มแชร์ แล้วเลือก “เพิ่มไปยังหน้าจอโฮม”

03

คอมพิวเตอร์
ใช้ Chrome หรือ Edge แล้วเลือกไอคอนติดตั้งที่แถบที่อยู่ หากเบราว์เซอร์รองรับ

ต้องเปิดเว็บผ่าน HTTPS และติดตั้งไฟล์ PWA บนโฮสต์ก่อน เมนูอาจแตกต่างกันตามอุปกรณ์
