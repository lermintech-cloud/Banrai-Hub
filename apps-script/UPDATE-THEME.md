# อัปเดตหลังบ้านให้ "หน้าตาส่วนกลาง" ทุกเครื่องเห็นเหมือนกัน

1. เปิด Google Sheets ที่ผูกสคริปต์ไว้ → **ส่วนขยาย → Apps Script**
2. เปิดไฟล์ `Code.gs` แล้ว **วางทับทั้งไฟล์** ด้วย `apps-script/Code.gs` ฉบับนี้
   - ตรวจบรรทัด `ADMIN_PASSWORD` ให้เป็นรหัสที่ต้องการ (ฉบับนี้คงเป็น `123456` ตามไฟล์ที่ส่งมา — **ควรเปลี่ยนก่อนใช้งานจริง**)
3. **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✎ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้**
   (URL `/exec` เดิมใช้ต่อได้ ไม่ต้องแก้ `config.js`)
4. อัปโหลดไฟล์เว็บชุดใหม่ขึ้น GitHub แล้วเปิดเว็บ → ตั้งค่า → 🎨 หน้าตา → **🔑 ผู้ดูแล: แก้หน้าตาส่วนกลาง** → ใส่รหัส → เลือกหน้าตา → **บันทึกเป็นหน้าตาส่วนกลาง**

ก่อนบันทึกครั้งแรก ทุกคนจะเห็นหน้าตาเริ่มต้น (คลาสสิก) ในโหมดส่วนกลาง
