# อัปเดตหลังบ้านให้ "บริการ สพป." แชร์ทุกเครื่อง

1. เปิด Google Sheets ที่ผูกสคริปต์ไว้ → **ส่วนขยาย → Apps Script**
2. เปิดไฟล์ `Code.gs` แล้ว **วางทับทั้งไฟล์** ด้วย `apps-script/Code.gs` ฉบับนี้
   - ตรวจบรรทัด `ADMIN_PASSWORD` ให้เป็นรหัสที่ต้องการ (ฉบับนี้คงค่าเดิมที่ส่งมา)
3. กด **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✎ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้**
   (ต้องทำข้อนี้ทุกครั้งที่แก้โค้ด ไม่งั้นเว็บยังเรียกโค้ดเก่า URL `/exec` เดิมใช้ต่อได้)
4. เปิดเว็บ → ตั้งค่า → 🏛 บริการ สพป. → ใส่รหัสผู้ดูแล → กด **บันทึกขึ้นออนไลน์** ครั้งแรก
   ระบบจะสร้างชีต `EsCats` และ `EsLinks` ให้เอง จากนั้นทุกเครื่องเห็นข้อมูลเดียวกัน

หมายเหตุ: ถ้ายังไม่อัปเดต `Code.gs` เว็บจะทำงานแบบเดิม (บริการ สพป. บันทึกเฉพาะเครื่อง)
